_Data → Assets_ lists the assets of all volumes.

## List

**Columns**: volume, file kind, dimensions, size, references, upload date and uploader.

**Search** by filename or title.

**Filter** by volume, file kind, usage, and missing alternative text.

## Detail page

- The file's metadata: path, URL, MIME type, dimensions, focal point, uploader and dates.
- A preview, for images.
- Its title and alternative text per site.
- The elements referencing it and those it references.
- The image transforms generated for it.

## Diagnostics

Assets with no references, images without alternative text, large files and oversized images.
