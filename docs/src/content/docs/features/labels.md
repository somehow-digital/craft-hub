---
title: Labels
description: Label items and filter lists by them.
---

Items of every list can be labeled with any number of labels. The labels are the same for all lists.

A label has a **name**, a **description**, an **icon** and a **color**. It's shown after the title of the labeled items by its icon in its color, with its name and description as tooltip.

## Using labels

- The button after an item's labels, shown while hovering its row, labels it right away.
- Every list can be filtered by labels, or by unlabeled items.
- Users need the _Label …_ permission of the page to label its items.

## Managing labels

Under _Hub → Settings → Labels_, users with the _Manage labels_ permission can create, change, order and delete labels.

Each label shows the lists it's used in with the number of items labeled, linking to them filtered by it.

| Action     | Effect                                                    |
| ---------- | --------------------------------------------------------- |
| **Clear**  | Removes the label from all items, but keeps the label.    |
| **Delete** | Deletes the label and unlabels all items labeled with it. |

## Turning labels off

Admins can disable labels under _Hub → Settings → Labels_. Lists then show no labels and can neither be labeled nor filtered by them.

Labels can still be managed, and items keep their labels for when labels are enabled again.
