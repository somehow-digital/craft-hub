## Requirements

- Craft CMS 5.11.0 or later
- PHP 8.2 or later

## Install

Install the plugin from the [**Plugin Store**](https://plugins.craftcms.com/hub) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-hub):

```bash
composer require somehow-digital/craft-hub
php craft plugin/install hub
```
